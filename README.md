# blu-autoOpenVoiceTextChat

Automatically opens the text chat of any voice channel you join.

## Features

- Auto-opens text chat upon joining a voice channel.
- Configurable delay before opening the chat.
- Supports both standard voice channels and stage channels.

## Settings

- **Enabled**: Toggle the plugin functionality.
- **Delay**: Set how long to wait (in milliseconds) before opening the text chat after joining.
